游戏内容攻略

掌握游戏流程和BOSS攻略

第一幕 - 罗格营地

主线任务

  1. 救出迪卡凯恩 - 前往邪恶洞穴
  2. 杀死血鸟 - 冰冷之原→埋骨之地
  3. 寻找凯恩之书 - 黑暗森林→黑色荒地
  4. 杀死安达利尔 - 修道院→地下墓穴

BOSS攻略: 安达利尔

  • 弱点: 火/冰系伤害
  • 技能: 毒云、冲锋、恐惧
  • 建议: 保持距离，使用火/冰技能

第二幕 - 鲁·高因

主线任务

  1. 寻找赫拉迪克之杖 - 干燥高地→死亡神殿
  2. 寻找方块 - 遥远的绿洲→蛆虫巢穴
  3. 组合法杖 - 神秘避难所找赫拉森日记
  4. 杀死都瑞尔 - 塔拉夏的古墓

BOSS攻略: 都瑞尔

  • 弱点: 火/电系伤害
  • 技能: 寒冰新星、冰冻光环
  • 建议: 堆冰抗，使用火技能

第三幕 - 库拉斯特海港

主线任务

  1. 杀死邪恶之手 - 蜘蛛森林
  2. 寻找吉得宾 - 庞大湿地→科克
  3. 保护凯恩 - 库拉斯特商场
  4. 杀死墨菲斯托 - 憎恨的囚牢

BOSS攻略: 墨菲斯托

  • 弱点: 闪电/冰系伤害
  • 技能: 充能弹、传送、审判光环
  • 建议: 注意躲避充能弹

第四幕 - 群魔堡垒

主线任务

  1. 摧毁灵魂石 - 火焰之河
  2. 杀死暗黑破坏神 - 混沌要塞

BOSS攻略: 暗黑破坏神

  • 弱点: 冰系伤害
  • 技能: 火焰风暴、紫电、骨牢
  • 建议: 保持移动，堆火抗

第五幕 - 哈洛加斯

主线任务

  1. 拯救野蛮人 - 血腥丘陵
  2. 摧毁地狱熔炉 - 火焰之河
  3. 开启通往世界之石的道路
  4. 杀死巴尔 - 世界之石要塞

BOSS攻略: 巴尔

  • 弱点: 毒素/魔法伤害
  • 技能: 召唤、传送、死亡之触
  • 建议: 先清小怪，注意躲避
